Automation · Growve 2.5 h → 30 min a day

Daily Amazon Monitoring for 15 Brands

Account Health Monitor + BSR Monitoring (browser extensions)

Problem

Every day, someone checked Account Health, Performance Notifications and support cases for 15 brands in the US and Canada (about 30 brand and country switches), then checked whether 20 products across 12 brands still held #1 Best Sellers Rank (7 steps each). It took about 2.5 hours.

What I built

Two browser extensions. One switches brand and country, reads each page, skips anything already reported, and drafts the Brand Manager emails and team tracker. The other opens each product, records its rank, flags any change since the last check, and builds the report. It pauses if a verification page appears.

Result

The routine now takes about 30 minutes, including a person reviewing everything before it's sent. A log of past reports stops the same issue being sent twice.

RGenie Assistant: Lost-Shipment Claims

Chrome extension for Amazon FBA reimbursement claims

Problem

To claim money back for lost inbound FBA shipments, each claim needed the Bill of Lading PDF opened, the shipment ID matched, proof uploaded to Reimbursement Genie and UPS proof printed, all by hand.

What I built

A Chrome extension that reads the local BOL PDFs, matches shipment IDs, uploads the proof to Reimbursement Genie and triggers the UPS proof printing.

Result

No more typing shipment details into each claim. I shipped 84 versions in 3 weeks as the workflow was refined.

Hermes: My Self-Hosted AI Assistant

An AI agent on an old laptop, reachable from Telegram anywhere

I turned an old laptop into a home server and set up Hermes, an AI agent I can message on Telegram. It scans OnlineJobs.ph for jobs that match my profile (I apply myself, as the site's rules require), alerts me to important emails, manages my calendar, maintains the server, and runs scheduled jobs. For example, it starts my marketplace alert bot at 10 a.m. and 10 p.m. instead of keeping it running all day, which saves memory.

One assistant handles job leads, email, calendar and server upkeep. It spreads its work across several free AI models and uses paid ones only as a fallback.

Casper: Telegram File-Backup Bot

Python Bot That Turns an Android Tablet into a Media Server

Built a Telegram bot in Python that pulls new files from Google Drive, converts videos to phone-playable MP4, uploads each file to the right topic in a private Telegram group, then frees the local copy. It skips duplicates by file fingerprint, downloads links on command, keeps a searchable index, and runs its own nightly self-check, heat and battery guard, and encrypted weekly backups.

Key Impact: 6,800+ files indexed and searchable with /find; uploads up to 2 GB per file, past the standard 50 MB bot limit; 11 releases from v1.0 to v2.0.
