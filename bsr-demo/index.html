BSR Monitoring

A browser extension I built for the daily Best Sellers Rank check. It opens each tracked product in turn, reads the rank line, marks Yes if the product is #1 in its expected category (or copies the actual rank), flags anything that changed since the last check, and builds the team report. Press Run all. Partway through, a verification page appears and the run waits for you.

Recreated for this portfolio with sample data. No real products, brands or marketplace pages are shown.

    What it replaced

    Seven steps per product, down to one run

    Before For each product, by hand

    1. Open the product link from the tracking sheet
    2. Copy the ASIN from the address bar
    3. Search the page for it to reach Product details
    4. Read the Best Sellers Rank sub-category line
    5. Compare it with the expected category: is it #1?
    6. Write the result in the sheet
    7. Repeat for all 20, then build the team message

    After With BSR Monitoring

    1. Press Run all
    2. Clear a verification page yourself if one appears
    3. Check anything flagged red or changed
    4. Copy the report into the team chat

    It visits one product at a time in a visible tab, never tries to get past a verification page, never changes anything on the site, and never posts the report itself. History is kept so a product that lost #1 is flagged straight away.
