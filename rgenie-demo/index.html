RGenie Assistant

A Chrome extension I built to automate lost inbound FBA shipment claims. It reads the BOL PDFs in a local folder, finds each shipment ID, uploads the proof to the matching claim, and queues the UPS proof for printing. Press Run audit to watch it work.

What it replaced

One click instead of a manual loop

Before Per claim, by hand

  1. Open the next BOL PDF from the folder
  2. Read the shipment ID and tracking number
  3. Search the reimbursement portal for that claim
  4. Open the claim and upload the BOL/POD proof
  5. Look up the UPS tracking proof
  6. Print it and file it
  7. Repeat for every shipment

After With RGenie Assistant

  1. Press Run audit
  2. Review the short list of claims it flags as missing proof

Everything else (reading, matching, uploading and printing) runs on its own, the same way every time. I also wrote the SOP the team follows when using it.
